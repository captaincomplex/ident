Flight Wall

A wall that shows your airline crew roster — not whatever plane happens to be overhead. It knows what to display by state, tracks your live flight while airborne, and estimates your time home.

In-flight view on a 128×32 panel: route arc with a moving aircraft marker, landing time, and estimated home time.

What it does

Built around an easyJet LGW roster exported from eCrew, with airline, base and timezone all configurable.

Reads your roster

Primary path is an iCal feed (the eCrew calendar export) parsed automatically. Fallback is a manual upload of the eCrew Personal Crew Schedule Report PDF, or any .ics file.

Knows what to show

A state engine picks the display for where you are in your duty cycle.

day offstandby next dutyreported in-flightturnaround heading home

Tracks the live flight

While airborne it polls a flight-data provider for the active sector, merging actual off/on times, position and ETA so the wall follows reality, not just the schedule.

Estimates time home

on-chocks → +30 min debrief → +walk-to-car → +commute → home. Commute is a slider, or an optional live Google Maps drive time at debrief o'clock.

Timezone aware

Everything is stored in UTC and shown as UTC, Local Base, or Local Station at the flick of a toggle.

Web control panel

A Flask panel for uploads, sliders, the timezone toggle and a live preview — including a time-travel field to preview what the wall will show when you land.

Display outputs

Three outputs, selectable in the panel.

Full LED — 128×32

The recommended build (two chained 64×32 HUB75 panels). Airborne, it shows a full-width great-circle route arc with a moving aircraft marker; landing and home times sit in the corners.

Compact LED — 64×32

Half the panel, lower cost. Everything still fits, but a 64‑px row holds ~12 characters, so the in-flight view stacks route, progress track and times; long routes scroll.

Vestaboard (split-flap)

A 6×22 mechanical grid — great for the text states, weak for a smooth map. The route reduces to a coarse chip-based progress bar. A VestaboardRenderer is included.

Hardware (suggested)

PartNotes
Raspberry Pi Zero 2 W (or Pi 4)Handles the roster / timezone / state logic comfortably.
Adafruit RGB Matrix Bonnet / HATSaves hand-wiring the HUB75 GPIO.
2 × 64×32 HUB75 RGB panelsChained to 128×32 — room for text; a single 64×32 works with more truncation.
5V / 4A+ PSULED panels are hungry — don't power them from the Pi.

Run the simulator

No hardware needed — renders the wall in your browser.

python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m ident.main            # simulator + web panel on :8080

Open http://localhost:8080, drop in your roster PDF, and the wall renders live.

Live tracking (AeroDataBox, Flightradar24 API, or OpenSky), Google Maps drive time, the physical LED output and the Vestaboard API need your own keys / hardware, so they're written and guarded but tuned on first run. The eCrew PDF parsing, AIMS iCal format, state machine, timezone conversion and home-time maths are verified against real data.
